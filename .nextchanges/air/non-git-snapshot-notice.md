* `air run` from a directory that is not a git repository now says so before packaging, with the number of files and their uncompressed size (or that it reuses the cached snapshot), suggests `code_source.include_paths` or a `.gitignore` when the files total 64 MiB or more, and warns about listed paths it leaves out, such as nested git repositories. `--dry-run` no longer counts those paths. The notice is not printed with `-o json`. ([#7618](https://github.com/databricks/cli/pull/7618))
