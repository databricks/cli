* `air run -o json` now reports config-validation errors as a JSON error envelope instead of plain text. Rejected credentials report `UNAUTHENTICATED`, other workspace client setup errors (such as an unknown profile) report `INVALID_ARGS`, and with `--dry-run` a missing permission on `config:validate` reports the new `PERMISSION_DENIED` code. ([#7864](https://github.com/databricks/cli/pull/7864))
