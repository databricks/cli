* Update `go.yaml.in/yaml` from v3 to [v4.0.0](https://github.com/yaml/go-yaml/releases/tag/v4.0.0). YAML syntax errors now report the line the problem is on, `air run` config validation errors gain a `yaml: construct errors: line N:` prefix, and multi-line strings with trailing spaces are written as block scalars instead of quoted strings.
