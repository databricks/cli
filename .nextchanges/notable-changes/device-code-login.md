* Introduce device code login: `databricks auth login --use-device-code` logs in from a machine that cannot open a browser, such as a headless server or an SSH session, by approving the login in a browser on another device. It no longer requires `DATABRICKS_CLI_DEVICE_CODE=true`. See [docs/device-code-login.md](https://github.com/databricks/cli/blob/main/docs/device-code-login.md).
