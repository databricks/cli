* `bundle deploy` now lists the per-resource actions it took (e.g. `Created jobs.my_job`) followed by summary lines: `Files: N uploaded, N deleted` when any file was synced, and `Resources: 1 created, 0 changed, 1 deleted, 3 unchanged.`. `bundle destroy` prints a matching `Destroy: N deleted.` line. With `--select`, the resource summary appends `, N not selected`. Pass `--quiet`/`-q` to print only the summary lines. ([#5720](https://github.com/databricks/cli/pull/5720))
