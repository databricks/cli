The direct deployment engine is now the default when nothing is configured. Bundles that still have Terraform state are migrated automatically: the deploy runs on Terraform as before, and afterwards the state is converted to the direct engine if a dry-run of the conversion comes back clean. To opt out, set `engine: terraform` under `bundle` in your `databricks.yml` or set `DATABRICKS_BUNDLE_ENGINE=terraform`. See https://docs.databricks.com/aws/en/dev-tools/bundles/direct
