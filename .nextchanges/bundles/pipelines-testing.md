* Add the experimental `testing` property of pipelines, with the test sources and test-only dependencies that `databricks pipelines test` runs with. It needs `DATABRICKS_BUNDLE_ENABLE_EXPERIMENTAL_PIPELINE_TESTING=true`. Everyone who deploys the bundle needs this CLI version with the variable set: a deploy from an older CLI that changes the pipeline removes its `testing`. ([#7300](https://github.com/databricks/cli/pull/7300), [#7437](https://github.com/databricks/cli/pull/7437), [#7439](https://github.com/databricks/cli/pull/7439))
