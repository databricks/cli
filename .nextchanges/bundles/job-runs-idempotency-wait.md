direct: the experimental `job_runs` resource now waits for the run to finish (printing the run page URL while it waits), exposes its output fields (e.g. `${resources.job_runs.<name>.state.result_state}`), and dedupes runs on deploy retries. If the tracked run no longer exists remotely (e.g. deleted or aged out of run history), a redeploy re-triggers a fresh run instead of failing. Set the new `rerun` field to force a fresh run of an otherwise-unchanged config.
