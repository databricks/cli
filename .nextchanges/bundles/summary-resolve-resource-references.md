* `bundle summary` (text and JSON output) now shows the deployed values of `${resources.*}` references instead of the references, for example a synced table named after its catalog, and builds resource URLs from them, so `bundle open` and `pipelines open` open the right page. References to values that are not known locally (resources not deployed yet, fields only the workspace has) and to sensitive fields stay as they are. Synced database table URLs now point to the table in Catalog Explorer. ([#8111](https://github.com/databricks/cli/pull/8111))
