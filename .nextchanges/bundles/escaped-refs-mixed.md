Fixed two cases where a `$${...}` escape and a real reference in the same string interfered. `"$${foo} ${foo}"` resolved to `"$<value> ${foo}"`, corrupting the literal and leaving the real reference unresolved, and an escaped placeholder next to a `${resources.*}` reference failed the deploy with "unresolved references". Follow-up to [#6484](https://github.com/databricks/cli/pull/6484).
