* `current_user` in `bundle validate` and `bundle summary` now comes from `identity/me`, not SCIM `/Me`. Changed fields, before -> after: `name`: SCIM name -> given and family names; `displayName`: SCIM display name -> given and family names joined by a space; `emails`: SCIM list -> the user name as the primary email; `active`: SCIM flag -> account status is ACTIVE; `groups`: SCIM groups -> transitive parent groups, with only `value` and `display`; `roles` and `entitlements`: SCIM values -> no longer included. ([#7714](https://github.com/databricks/cli/pull/7714))
