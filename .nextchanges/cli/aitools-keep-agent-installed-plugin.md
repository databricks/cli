* `databricks aitools install`, `databricks aitools update` and the automatic install now see a Databricks plugin for Codex or GitHub Copilot installed with the agent's own CLI. When the agent's CLI is not on PATH they keep the plugin and add or update no skill files next to it, and `install` and `update` remove the skill files an earlier run added, so the agent no longer loads every Databricks skill twice. `install --skills-only` skips such an agent and names the agent's own command that removes the plugin. ([#7917](https://github.com/databricks/cli/pull/7917))
