`databricks environments setup-local` now manages `databricks-connect` in a single place: it removes any `databricks-connect` pin from `[project].dependencies`, optional-dependency extras, and every dependency group, keeping only the managed pin in `[dependency-groups].dev` at the compute target's version. Previously a `databricks-connect` pin shipped by a template in `[project].dependencies` conflicted with the managed dev pin and made `uv sync` fail; each removed pin is now reported with the new `W_DBCONNECT_CONSOLIDATED` warning. Wildcard version pins such as `==15.1.*` are also now checked for conflicts with the environment's constraints.
