* Support `file:<path>` selectors in `pipelines run` and pipeline `bundle run` with `--refresh` and `--full-refresh`. Both flags now accept space-separated selectors inside quotes or repeated flags; bare names select tables and `table:` is optional. Replace comma-separated lists such as `--refresh orders,payments` with `--refresh "orders payments"`. Use backticks for names or paths containing spaces or commas, and double backticks to escape a literal backtick. ([#7184](https://github.com/databricks/cli/pull/7184))
