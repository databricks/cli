* `databricks aitools update` no longer replaces skill files with the Databricks plugin for Claude Code, Codex or GitHub Copilot when you installed them with `databricks aitools install --skills-only` from this release on while the agent's CLI was on PATH. For an earlier `--skills-only` install, run `databricks aitools install --skills-only` again, with the agent's CLI on PATH, to keep the skill files, or run `databricks aitools install` without `--skills-only` to switch to the plugin. ([#7831](https://github.com/databricks/cli/pull/7831))
