* `databricks auth profiles --skip-validate` now omits `valid` from its JSON output instead of reporting `false` for every profile. Without the flag, every profile still has `valid` set to `true` or `false`; scripts that compared `valid` to `false` in `--skip-validate` output should check for a missing `valid` instead. ([#7897](https://github.com/databricks/cli/pull/7897))
