* Alt with a key that isn't a letter (Alt+Enter, Alt+arrows, Alt+Space) no longer acts as that key in prompts, selection lists and the pager. Alt+Enter used to submit and Alt+Left used to move the cursor.
* Selection lists treat pasted text as typed search text, and ignore it outside search. Pasting `j` or `/` no longer moves the cursor or opens search. The table view's search no longer inserts `alt+f` for Alt+F or `[text]` for a paste.
