* Automatic installation of Databricks AI tools no longer moves a Databricks skill that you put into a coding agent's skills directory (for example `~/.cursor/skills/databricks-sql`) to a temporary directory when no `databricks aitools install` has run yet. While that skill is there it installs no skills, though agents that use the Databricks plugin still get it; a later CLI version finishes the install once you move the skill out. ([#8071](https://github.com/databricks/cli/pull/8071))
