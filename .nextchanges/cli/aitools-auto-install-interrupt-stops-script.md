* On Linux and macOS, pressing Ctrl-C at the question to install Databricks AI tools now stops the script, loop or `&&` list that ran the command, as Ctrl-C during the command does. The CLI records the answer first and then ends by the signal. Ctrl-C, a request to terminate or a closed terminal while the CLI checks whether to install the tools now also ends the CLI by that signal. A closed terminal now also stops a coding agent's CLI that is installing its plugin. ([#7874](https://github.com/databricks/cli/pull/7874))
