* Automatic installation of Databricks AI tools no longer installs for the first time without asking when the CLI runs with no terminal (ssh without a terminal, nohup, cron, an IDE extension); the first install waits for a run that can ask. Updates of an existing installation still run without a terminal, and coding agents still get the tools without a question. ([#7834](https://github.com/databricks/cli/pull/7834))
