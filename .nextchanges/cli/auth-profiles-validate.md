* `databricks auth profiles` is now a fast, offline listing of the configured profiles. It no longer validates credentials or contacts the workspace, so the `Valid` column (and the `valid` field in `--output json`) has been removed. Use `databricks auth describe` to check whether a profile can authenticate. `--skip-validate` is still accepted but has no effect ([#5216](https://github.com/databricks/cli/pull/5216)).
