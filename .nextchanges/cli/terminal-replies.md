* The TUI libraries now query the terminal at startup. So that the answers don't end up at the shell prompt (as text like `^[[?2026;2$y`), prompts, selection lists, the pager and the table viewer wait for the terminal to answer before they exit, for at most 2 seconds; keys typed during that wait are discarded. Forms in `databricks apps` and `databricks aitools` don't wait, so their answers can still appear at the shell prompt after a very quick exit. ([#7742](https://github.com/databricks/cli/pull/7742))
