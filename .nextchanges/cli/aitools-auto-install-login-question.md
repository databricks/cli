* `databricks auth login` now asks once, after the profile is saved, whether to install Databricks AI tools for the coding agents on this machine and keep them up to date. A "yes" installs them right after the login, and a "no" turns auto-install off. The question is not asked in non-interactive runs, when a coding agent runs the CLI, or when no coding agent would get the tools. ([#8142](https://github.com/databricks/cli/pull/8142))
