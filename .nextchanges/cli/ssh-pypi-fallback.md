* `databricks ssh connect` now downloads the Linux CLI binaries it uploads for the SSH server from the `databricks` package on PyPI when GitHub can't be reached. It uses `PIP_INDEX_URL` or `index-url` from the per-user pip config when set, else pypi.org, over HTTPS only, and checks each wheel against the SHA-256 digest the index lists. ([#7852](https://github.com/databricks/cli/pull/7852))
