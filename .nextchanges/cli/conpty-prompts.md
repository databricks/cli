* Interactive prompts and pagers now work in bash and other MSYS2 shells from Git for Windows when stdin is a console: in Windows Terminal, conhost and the VS Code terminal, and in mintty with ConPTY (the default since Git for Windows 2.47). They stay disabled in mintty with ConPTY turned off (`MSYS=disable_pcon`). ([#7699](https://github.com/databricks/cli/pull/7699))
