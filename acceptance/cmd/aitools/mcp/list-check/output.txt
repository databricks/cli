
=== Install a service that needs no sign-in and one that does

>>> [CLI] aitools mcp add --profile logfood --names system.ai.genie_one_mcp,system.ai.github --agents claude-code
Profile logfood ([DATABRICKS_URL])
Agents (named with --agents): claude-code

genie_one_mcp-logfood  system.ai.genie_one_mcp
  claude-code  installed  [TEST_TMP_DIR]/home/.claude.json

github-logfood  system.ai.github
  claude-code  installed  [TEST_TMP_DIR]/home/.claude.json
system.ai.github needs sign-in. Run: DATABRICKS_CONFIG_FILE=[TEST_TMP_DIR]/.databrickscfg databricks aitools mcp login system.ai.github --profile logfood

=== list --check: the token mints, and GitHub needs sign-in

>>> [CLI] aitools mcp list --check
Profile logfood  ([DATABRICKS_URL], config file [TEST_TMP_DIR]/.databrickscfg)  token ok
  genie_one_mcp-logfood    system.ai.genie_one_mcp        Claude Code
  github-logfood           system.ai.github               Claude Code  sign-in needed

=== Once the sign-in completes, GitHub is signed in

>>> [CLI] api post /api/2.1/unity-catalog/mcp-services/system.ai.github/user-credentials --profile logfood --json {}

>>> [CLI] aitools mcp list --check
Profile logfood  ([DATABRICKS_URL], config file [TEST_TMP_DIR]/.databrickscfg)  token ok
  genie_one_mcp-logfood    system.ai.genie_one_mcp        Claude Code
  github-logfood           system.ai.github               Claude Code  signed in
