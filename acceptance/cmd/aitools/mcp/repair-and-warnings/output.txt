=== Claude Code reads its config from another directory: list says path changed, and remove keeps the entry

>>> [CLI] aitools mcp list
Profile logfood  ([DATABRICKS_URL])
  genie_one_mcp-logfood    system.ai.genie_one_mcp        Claude Code (path changed), Codex CLI

>>> [CLI] aitools mcp remove --names genie_one_mcp-logfood --agents claude-code
Skipped genie_one_mcp-logfood: Claude Code reads its config from [TEST_TMP_DIR]/home/moved-claude/.claude.json now, but genie_one_mcp-logfood was written to [TEST_TMP_DIR]/home/.claude.json; left in place, and its record kept

>>> jq .mcpServers | keys home/.claude.json
[
  "genie_one_mcp-logfood"
]
