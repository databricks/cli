=== Claude Code reads its config from another directory: list says path changed, and remove takes the entry out of the file it was written to

>>> [CLI] aitools mcp list
Profile logfood  ([DATABRICKS_URL], config file [TEST_TMP_DIR]/.databrickscfg)
  genie_one_mcp-logfood    system.ai.genie_one_mcp        Claude Code (path changed), Codex CLI
