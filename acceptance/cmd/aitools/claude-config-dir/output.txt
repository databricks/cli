
=== Plugin installed only in the custom config directory

>>> CLAUDE_CONFIG_DIR=custom [CLI] clusters list
ID    Name                State
4321  some-test-cluster   
9876  some-other-cluster  

=== Custom directory takes precedence over the default installation

>>> CLAUDE_CONFIG_DIR=missing [CLI] clusters list
Databricks skills are not installed. To work with Databricks reliably, first run: databricks aitools install
ID    Name                State
4321  some-test-cluster   
9876  some-other-cluster  

=== Exempt commands never hint, even without the tooling

>>> CLAUDE_CONFIG_DIR=missing [CLI] current-user me
"[USERNAME]"

=== Empty override uses the default installation

>>> CLAUDE_CONFIG_DIR= [CLI] clusters list
ID    Name                State
4321  some-test-cluster   
9876  some-other-cluster  

=== Unset override uses the default installation

>>> [CLI] clusters list
ID    Name                State
4321  some-test-cluster   
9876  some-other-cluster
