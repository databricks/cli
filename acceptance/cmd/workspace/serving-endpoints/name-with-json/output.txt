
=== create: NAME as the argument together with --json

>>> [CLI] serving-endpoints create my-endpoint --no-wait --json {"description": "from arg"}
{"name":"my-endpoint","description":"from arg"}

=== create: NAME inside --json still works

>>> [CLI] serving-endpoints create --no-wait --json {"name": "other-endpoint"}
{"name":"other-endpoint"}

=== create: the same name in both places is fine

>>> [CLI] serving-endpoints create third-endpoint --no-wait --json {"name": "third-endpoint"}
{"name":"third-endpoint"}

=== create: different names are rejected

>>> musterr [CLI] serving-endpoints create my-endpoint --json {"name": "something-else"}
Error: the endpoint name "my-endpoint" doesn't match "name" "something-else" in --json; pass it in one place only

=== update-config: NAME from --json when the argument is omitted

>>> [CLI] serving-endpoints update-config --no-wait --json {"name": "my-endpoint", "served_entities": [{"entity_name": "main.default.m", "entity_version": "1", "workload_size": "Small"}]}
{"name":"my-endpoint"}

=== update-config: the argument still works

>>> [CLI] serving-endpoints update-config my-endpoint --no-wait --json {"served_entities": [{"entity_name": "main.default.m", "entity_version": "2", "workload_size": "Small"}]}
{"name":"my-endpoint"}
