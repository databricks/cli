
=== Plain --json request body: skeleton is the request struct itself

>>> [CLI] vector-search-endpoints create-endpoint --generate-skeleton
{
  "budget_policy_id": "",
  "endpoint_type": "",
  "name": "",
  "target_qps": 0,
  "usage_policy_id": ""
}

=== Request-body-field command: skeleton is the body field, positional args relaxed

>>> [CLI] entity-tag-assignments create --generate-skeleton
{
  "entity_name": "",
  "entity_type": "",
  "source_type": "",
  "tag_key": "",
  "tag_value": "",
  "update_time": {},
  "updated_by": ""
}

=== --generate-skeleton is incompatible with --json
Error: --generate-skeleton cannot be combined with --json
