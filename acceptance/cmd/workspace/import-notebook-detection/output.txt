
=== AUTO imports it as a notebook, like the legacy import-file endpoint. Overwrite can't make it a file

>>> [CLI] workspace import /Workspace/Users/[USERNAME]/[UNIQUE_NAME]/notebook/bom.sql --file bom.sql --format AUTO

>>> musterr [CLI] workspace import /Workspace/Users/[USERNAME]/[UNIQUE_NAME]/notebook/bom.sql --file bom.sql --format RAW --overwrite
Error: Requested node type [FILE] is different from the existing node type [NOTEBOOK]

=== RAW imports it as a file, like this CLI. Overwrite can't make it a notebook

>>> [CLI] workspace import /Workspace/Users/[USERNAME]/[UNIQUE_NAME]/file/bom.sql --file bom.sql --format RAW

>>> musterr [CLI] workspace import /Workspace/Users/[USERNAME]/[UNIQUE_NAME]/file/bom.sql --file bom.sql --format AUTO --overwrite
Error: Node named 'bom.sql' already exists

>>> [CLI] workspace list /Workspace/Users/[USERNAME]/[UNIQUE_NAME]/notebook -o json
NOTEBOOK /Workspace/Users/[USERNAME]/[UNIQUE_NAME]/notebook/bom

>>> [CLI] workspace list /Workspace/Users/[USERNAME]/[UNIQUE_NAME]/file -o json
FILE /Workspace/Users/[USERNAME]/[UNIQUE_NAME]/file/bom.sql
