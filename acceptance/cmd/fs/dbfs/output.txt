
=== Create a directory and write a file in it

>>> [CLI] fs mkdir dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir

>>> [CLI] fs cp big.bin dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir/big.bin
big.bin -> dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir/big.bin

=== Read the file back

>>> cmp big.bin big.back
contents match

=== Writing over an existing file needs --overwrite

>>> [CLI] fs cp big.bin dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir/big.bin
big.bin -> dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir/big.bin (skipped; already exists)

>>> [CLI] fs cp --overwrite big.bin dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir/big.bin
big.bin -> dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir/big.bin

=== Writing into a directory that does not exist fails

>>> [CLI] fs cp big.bin dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/missing/big.bin
Error: no such directory: /tmp/fs-dbfs-[UNIQUE_NAME]/missing

Exit code: 1

=== List a directory, then a file

>>> [CLI] fs ls dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir
big.bin

>>> [CLI] fs ls dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir/big.bin
Error: not a directory: /tmp/fs-dbfs-[UNIQUE_NAME]/dir/big.bin

Exit code: 1

=== cat a directory fails

>>> [CLI] fs cat dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir
Error: not a file: /tmp/fs-dbfs-[UNIQUE_NAME]/dir

Exit code: 1

=== rm a non-empty directory needs -r

>>> [CLI] fs rm dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir
Error: directory not empty: /tmp/fs-dbfs-[UNIQUE_NAME]/dir

Exit code: 1

>>> [CLI] fs rm -r dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir

>>> [CLI] fs ls dbfs:/tmp/fs-dbfs-[UNIQUE_NAME]/dir
Error: no such directory: /tmp/fs-dbfs-[UNIQUE_NAME]/dir

Exit code: 1
