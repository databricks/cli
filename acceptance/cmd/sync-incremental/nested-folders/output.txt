
=== New file in nested folders

>>> [CLI] sync src /Users/[USERNAME]/sync-[UNIQUE_NAME]
Initial Sync Complete
Uploaded dir1/dir2/dir3
Uploaded dir1/dir2/dir3/foo.txt

>>> remote_tree
DIRECTORY dir1
DIRECTORY dir1/dir2
DIRECTORY dir1/dir2/dir3
FILE dir1/dir2/dir3/foo.txt

>>> snapshot_files
dir1/dir2/dir3/foo.txt

=== Delete the file; the empty remote folders are removed too

>>> [CLI] sync src /Users/[USERNAME]/sync-[UNIQUE_NAME]
Deleted dir1
Deleted dir1/dir2
Deleted dir1/dir2/dir3
Deleted dir1/dir2/dir3/foo.txt
Initial Sync Complete

>>> remote_tree

>>> snapshot_files

=== Spaces, plus and hash in folder and file names

>>> [CLI] sync src /Users/[USERNAME]/sync-[UNIQUE_NAME]
Initial Sync Complete
Uploaded dir1/a b+c/c+d e
Uploaded dir1/a b+c/c+d e/e+f g#i.txt

>>> remote_tree
DIRECTORY dir1
DIRECTORY dir1/a b+c
DIRECTORY dir1/a b+c/c+d e
FILE dir1/a b+c/c+d e/e+f g#i.txt

>>> snapshot_files
dir1/a b+c/c+d e/e+f g#i.txt
