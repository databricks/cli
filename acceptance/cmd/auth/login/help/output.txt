
>>> [CLI] auth login --help
Log into a Databricks workspace or account.

This command authenticates via OAuth in the browser and saves the result
to a configuration profile (in [DATABRICKS_CONFIG_FILE] by default). Other Databricks CLI
commands and SDKs can use this profile via the --profile flag. For more
information, see:
  AWS: https://docs.databricks.com/dev-tools/auth/index.html
  Azure: https://learn.microsoft.com/azure/databricks/dev-tools/auth
  GCP: https://docs.gcp.databricks.com/dev-tools/auth/index.html

If no host is provided, the CLI opens login.databricks.com where you can
authenticate and select a workspace.

On a machine that cannot open a browser, use --use-device-code to approve
the login in a browser on another device.

The positional argument is resolved as a profile name first. If no profile
with that name exists and the argument looks like a URL, it is used as a
host. The positional argument cannot be combined with --host or --profile;
use the flags directly to specify both.

The host URL may include query parameters to set the workspace and account ID:

  databricks auth login --host "https://<host>?w=<workspace_id>&account_id=<id>"

The workspace ID may be passed as ?w= (preferred), ?o= (legacy), or
?workspace_id=. Note: URLs containing "?" must be quoted to prevent shell
interpretation.

If a profile with the given name already exists, it is updated. Otherwise
a new profile is created.

Usage:
  databricks auth login [PROFILE] [flags]

Flags:
      --client-id string                    OAuth client ID to use for U2M authentication
      --configure-cluster[=true|false]      Prompts to configure cluster
      --configure-serverless[=true|false]   Prompts to configure serverless
  -h, --help[=true|false]                   help for login
      --resource stringArray                RFC 8707 resource indicator to scope the login to (repeatable). Requires --host.
      --scopes string                       Comma-separated list of OAuth scopes to request (defaults to 'all-apis')
      --skip-workspace[=true|false]         Skip workspace selection for account-level access
      --timeout duration                    Timeout for completing login challenge in the browser (default 1h0m0s)
      --use-device-code[=true|false]        Log in with a device code, using a browser on another device

Global Flags:
      --account-id string     Databricks Account ID
      --debug[=true|false]    enable debug logging
      --host string           Databricks Host
  -o, --output type           output type: text or json (default text)
  -p, --profile string        [DATABRICKS_CONFIG_FILE] profile
  -t, --target string         bundle target to use (if applicable)
      --workspace-id string   Databricks Workspace ID
