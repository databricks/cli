
=== Log in to the account

>>> [CLI] auth login --host [DATABRICKS_URL]?a=spog-acct-123 --profile account --use-device-code
Using a browser on another device, visit:
[DATABRICKS_URL]/device/verification

And enter the code:
WDJB-0001

Once finished, complete the login by running the same command with
--user-code WDJB-0001 and --confirmation-code set to the confirmation code
provided in your browser.

>>> [CLI] auth login --host [DATABRICKS_URL]?a=spog-acct-123 --profile account --use-device-code --user-code WDJB-0001 --confirmation-code FTFA-QQKY
Profile account was successfully saved

>>> [CLI] auth token --profile account
json.access_token = "oauth-token";

=== Log in to a workspace of the account

>>> [CLI] auth login --host [DATABRICKS_URL]?a=spog-acct-123&o=12345 --profile workspace --use-device-code
Using a browser on another device, visit:
[DATABRICKS_URL]/device/verification

And enter the code:
WDJB-0002

Once finished, complete the login by running the same command with
--user-code WDJB-0002 and --confirmation-code set to the confirmation code
provided in your browser.

>>> [CLI] auth login --host [DATABRICKS_URL]?a=spog-acct-123&o=12345 --profile workspace --use-device-code --user-code WDJB-0002 --confirmation-code FTFA-QQKY
Profile workspace was successfully saved

>>> [CLI] auth token --profile workspace
json.access_token = "oauth-token";
