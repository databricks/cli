
=== Scopes and client ID from the profile

>>> [CLI] auth login --profile scoped --use-device-code
Using a browser on another device, visit:
[DATABRICKS_URL]/device/verification

And enter the code:
WDJB-MJHT

Once finished, complete the login by running the same command with
--user-code WDJB-MJHT and --confirmation-code set to the confirmation code
provided in your browser.

>>> [CLI] auth login --profile scoped --use-device-code --user-code WDJB-MJHT --confirmation-code FTFA-QQKY
Profile scoped was successfully saved
