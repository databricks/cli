
=== Start the login without a profile

>>> [CLI] auth login --host [DATABRICKS_URL] --use-device-code
Using a browser on another device, visit:
[DATABRICKS_URL]/device/verification

And enter the code:
WDJB-MJHT

Once finished, complete the login by running the same command with
--user-code WDJB-MJHT and --confirmation-code set to the confirmation code
provided in your browser.

=== The first step stores the device code and saves no profile

>>> find.py home
home/.databricks/token-cache.json

>>> cache_keys
[
  "[DATABRICKS_URL]#device-code"
]

=== Confirm the login

>>> [CLI] auth login --host [DATABRICKS_URL] --use-device-code --user-code WDJB-MJHT --confirmation-code FTFA-QQKY

>>> [CLI] auth token --host [DATABRICKS_URL]
json.access_token = "oauth-token";

>>> cache_keys
[
  "[DATABRICKS_URL]"
]

=== An AI agent gets notes on passing the login on to the user

>>> AGENT=test-agent [CLI] auth login --host [DATABRICKS_URL] --profile agent --use-device-code
Using a browser on another device, visit:
[DATABRICKS_URL]/device/verification

And enter the code:
WDJB-MJHT

Note for AI agents (test-agent): give the URL and the code above to the user.
Do not open the URL or approve the login yourself: the user must approve it.
Ask the user for the confirmation code their browser shows.

Once finished, complete the login by running the same command with
--user-code WDJB-MJHT and --confirmation-code set to the confirmation code
provided in your browser.

>>> AGENT=test-agent [CLI] auth login --host [DATABRICKS_URL] --profile agent --use-device-code --user-code WDJB-MJHT --confirmation-code FTFA-QQKY
Profile agent was successfully saved
