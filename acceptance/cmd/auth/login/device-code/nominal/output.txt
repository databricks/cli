
=== Login with a host

>>> [CLI] auth login --host [DATABRICKS_URL] --profile test --use-device-code
Using a browser on another device, visit:
[DATABRICKS_URL]/device/verification

And enter the code:
WDJB-MJHT

Once finished, enter the confirmation code provided in your browser.
Confirmation code: Profile test was successfully saved

>>> [CLI] auth token --profile test
json.access_token = "oauth-token";

>>> [CLI] auth profiles
Name            Host                    Valid
test (Default)  [DATABRICKS_URL]  YES
