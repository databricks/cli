
=== Logout and delete dev
>>> [CLI] auth logout --profile dev --auto-approve --delete
Logged out of and deleted profile "dev".

=== Token cache keys after logout — the host keys are kept, staging shares them

=== Logout staging
>>> [CLI] auth logout --profile staging --auto-approve
Logged out of profile "staging". Use --delete to also remove it from the config file.
