
=== Feedback about a product command is routed to its team

>>> [CLI] feedback --command air run --run-id 123 --can-be-contacted   logs omitted the failure reason  
Thank you! Your feedback was sent. Reference: [UUID][0]

>>> print_requests.py //telemetry-ext
{
  "frontend_log_event_id": "[UUID][0]",
  "entry": {
    "fast_feedback_log": {
      "reference_event_id": "[UUID][1]",
      "parent_ui": "ModelTraining.AIRuntime",
      "origin": "air_run",
      "can_be_contacted": true,
      "ui_versions": "cli:[CLI_VERSION]",
      "user_agent": "cli/[CLI_VERSION] cmd/feedback run-id/123",
      "text": "logs omitted the failure reason"
    }
  }
}

=== Validation errors send nothing

>>> [CLI] feedback    
Error: feedback message must contain 1 to 10000 characters, including a visible one

>>> [CLI] feedback
Error: accepts 1 arg(s), received 0

Usage:
  databricks feedback MESSAGE [flags]

Examples:
  databricks feedback --command "bundle deploy" "deploy should print which resources changed"
  databricks feedback --command "air run" --run-id 123 "logs omitted the failure reason"

Flags:
      --can-be-contacted[=true|false]   Allow Databricks to contact you about this feedback
      --command string                  CLI command the feedback is about, for example "bundle deploy"
  -h, --help[=true|false]               help for feedback
      --run-id string                   ID of the job run the feedback is about
  -y, --yes[=true|false]                Confirm sending feedback written by an AI agent

Global Flags:
      --debug[=true|false]   enable debug logging
  -o, --output type          output type: text or json (default text)
  -p, --profile string       ~/.databrickscfg profile
  -t, --target string        bundle target to use (if applicable)


>>> [CLI] feedback deploy is slow
Error: the message must be one argument, but received 3; put quotes around the whole message, and around --command if it has several words

>>> [CLI] feedback --command bundle deploy deploy is slow
Error: the message must be one argument, but received 2; put quotes around the whole message, and around --command if it has several words

>>> [CLI] feedback --command bundle deploy -t dev hello
Error: invalid --command "bundle deploy -t dev"; it takes a command path such as "bundle deploy", without the databricks prefix, flags or arguments

>>> [CLI] feedback --run-id abc hello
Error: --run-id must be a positive job run ID

>>> [CLI] feedback --target dev hello
Error: --target selects a bundle target, which feedback does not use; use --profile to choose the workspace

=== Input errors are reported before authenticating

>>> env -u DATABRICKS_HOST -u DATABRICKS_TOKEN [CLI] feedback    
Error: feedback message must contain 1 to 10000 characters, including a visible one

>>> env -u DATABRICKS_HOST -u DATABRICKS_TOKEN AGENT=test-agent [CLI] feedback hello
Error: feedback from an AI agent must be confirmed by the user; run with --yes once the user approves the message

Note for AI agents (test-agent): show the user the exact feedback message and the flags you pass with it, such as --can-be-contacted, and pass --yes only after the user approves sending it
