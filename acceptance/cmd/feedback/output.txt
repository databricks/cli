
=== Feedback help explains content guidance and agent submissions

>>> [CLI] feedback --help
Send feedback about the Databricks CLI to Databricks.

Describe the command you ran, what happened, what you expected, and any
workaround. Use --command to name the command the feedback is about so it
reaches the team that owns it.

The message is sent with the workspace and user you are authenticated as and
the CLI user agent, which includes the CLI version, operating system and, if
detected, the AI agent running the CLI. No logs, files or transcripts are
collected. Do not include customer content, personally identifiable information
(PII), credentials or other sensitive data. Follow-up contact is opt-in with
--can-be-contacted. Feedback is sent even when DATABRICKS_CLI_DISABLE_TELEMETRY
is set, because this command explicitly submits feedback.

AI agents can submit feedback directly without asking the user for approval.
Use --can-be-contacted only if the user explicitly agrees to be contacted.
After a successful submission, tell the user that feedback was sent and include
the reference ID.

Usage:
  databricks feedback MESSAGE [flags]

Examples:
  databricks feedback --command "bundle deploy" "deploy should print which resources changed"
  databricks feedback --command "air run" --run-id 123 "logs omitted the failure reason"

Flags:
      --can-be-contacted[=true|false]   Allow Databricks to contact you about this feedback
      --command string                  CLI command the feedback is about, for example "bundle deploy"
  -h, --help[=true|false]               help for feedback
      --run-id string                   ID of the job run the feedback is about

Global Flags:
      --debug[=true|false]   enable debug logging
  -o, --output type          output type: text or json (default text)
  -p, --profile string       ~/.databrickscfg profile
  -t, --target string        bundle target to use (if applicable)

=== Input errors are reported before authenticating

>>> env -u DATABRICKS_HOST -u DATABRICKS_TOKEN [CLI] feedback    
Error: feedback message must contain 1 to 10000 characters, including a visible one

>>> env -u DATABRICKS_HOST -u DATABRICKS_TOKEN AGENT=test-agent [CLI] feedback --run-id abc hello
Error: --run-id must be a positive job run ID

>>> env -u DATABRICKS_HOST -u DATABRICKS_TOKEN AGENT=test-agent [CLI] feedback --yes=false hello
Flag --yes has been deprecated, omit this flag when sending feedback; skip the feedback command when declining
Error: feedback was not sent because --yes=false
