=== An AI agent needs the user's confirmation

>>> env AGENT=test-agent [CLI] feedback hello
Error: feedback from an AI agent must be confirmed by the user; run with --yes once the user approves the message

Note for AI agents (test-agent): show the user the exact feedback message and pass --yes only after the user approves sending it.

Exit code: 1

=== Validation errors

>>> [CLI] feedback    
Error: feedback message must contain 1 to 10000 characters

Exit code: 1

>>> [CLI] feedback --command no-such-command hello

Exit code: 1

>>> [CLI] feedback --command bundle no-such-command hello
Error: unknown command "bundle no-such-command"

Exit code: 1

>>> [CLI] feedback --run-id abc hello
Error: --run-id must be a positive job run ID

Exit code: 1
