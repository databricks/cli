
>>> [CLI] skills list
Pick the skill whose description matches the task.
Read the skill before you act on it.

-foo: A skill whose name starts with a hyphen.
demo-skill: A skill for tests.
future-skill: A skill that needs a newer CLI. (needs CLI 99.0.0 or newer)
guide-skill: A skill with a supporting file.
To read a skill, run: databricks skills read <name>
