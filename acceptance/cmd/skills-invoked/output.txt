
=== Env var sends the header on a workspace GET

>>> [CLI] current-user me

>>> print_requests.py --get //scim/v2/Me
{
  "headers": {
    "X-Databricks-Skills-Invoked": [
      "databricks-core,databricks:databricks-jobs"
    ]
  },
  "method": "GET",
  "path": "/api/2.0/preview/scim/v2/Me"
}
