
=== With pipeline testing, a folder after -e maps to its deployed folder

>>> [CLI] bundle validate -o json
{
  "job": [
    "-e /Workspace/Users/[USERNAME]/.bundle/editable-folder/default/files/project"
  ],
  "pipeline": [
    "-e /Workspace/Users/[USERNAME]/.bundle/editable-folder/default/files/project[test]"
  ]
}

=== Without pipeline testing, a folder after -e is an error, as before
Error: unable to determine if [TEST_TMP_DIR]/project is not a notebook
