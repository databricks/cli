=== A branch other than the target's git.branch

>>> musterr [CLI] bundle auto-deploy create -t prod --branch release
Error: git.branch is main for target prod, so a deploy from release would fail. Omit --branch, or change git.branch

=== An SSH origin

>>> musterr [CLI] bundle auto-deploy create
Error: auto-deploy needs the HTTPS URL of the repository, but the origin is git@github.com:acme/repo.git. Set bundle.git.origin_url to the HTTPS URL

=== Local variable values do not reach the deploys

>>> musterr [CLI] bundle auto-deploy create --var release_branch=hotfix
Error: auto-deploy deploys with the variable values in the configuration only, but --var overrides them here. Set the values as variable defaults or target overrides instead

>>> BUNDLE_VAR_release_branch=hotfix [CLI] bundle auto-deploy create -t staging
Error: auto-deploy deploys with the variable values in the configuration only, but BUNDLE_VAR_release_branch overrides them here. Set the values as variable defaults or target overrides instead

=== No origin remote

>>> musterr [CLI] bundle auto-deploy create
Error: auto-deploy needs the bundle in a Git repository with an origin remote. To add one, run: git remote add origin <url>
