=== The body of the bound page differs from the config, so the deploy updates it in place

>>> [CLI] bundle plan
update pages.chargeback

Plan: 0 to add, 1 to change, 0 to delete, 0 unchanged

>>> [CLI] bundle deploy

Updated pages.chargeback
Files: 1 uploaded, 0 deleted
Resources: 0 created, 1 changed, 0 deleted, 0 unchanged

=== The page keeps the state it had: the config does not set one

>>> [CLI] api get /api/2.0/knowledge/pages/[UUID]
{
  "display_name": "Chargeback",
  "body": "A reversal of a card payment.",
  "state": "PUBLISHED"
}

=== After unbind the page is no longer part of the bundle, so destroy leaves it alone

>>> [CLI] bundle deployment unbind chargeback

>>> [CLI] bundle destroy --auto-approve
All files and directories at the following location will be deleted: /Workspace/Users/[USERNAME]/.bundle/test-bind-page/default

Destroy: 0 deleted

>>> [CLI] api get /api/2.0/knowledge/pages/[UUID]
{
  "display_name": "Chargeback"
}
