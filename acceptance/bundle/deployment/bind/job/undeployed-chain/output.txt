
=== Bind a job whose dependency, not deployed yet, references another job that is not deployed yet

>>> [CLI] bundle deployment bind job_1 [EXTERNAL_JOB_ID] --auto-approve
Successfully bound job with an id '[EXTERNAL_JOB_ID]'
Run 'bundle deploy' to deploy changes to your workspace

>>> jq .state | map_values({__id__, depends_on, description: .state.description}) .databricks/bundle/default/resources.json
{
  "resources.jobs.job_1": {
    "__id__": "[EXTERNAL_JOB_ID]",
    "depends_on": [
      {
        "node": "resources.jobs.middle",
        "label": "${resources.jobs.middle.id}"
      }
    ],
    "description": "runs after ${resources.jobs.middle.id}"
  }
}
