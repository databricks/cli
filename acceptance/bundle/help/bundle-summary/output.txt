
>>> [CLI] bundle summary --help
Summarize resources deployed by this bundle with their workspace URLs.
Useful after deployment to see what was created and where to find it.

Usage:
  databricks bundle summary [flags]

Flags:
      --force-pull[=true|false]   Skip local cache and load the state from the remote workspace
  -h, --help[=true|false]         help for summary

Global Flags:
      --debug[=true|false]   enable debug logging
  -o, --output type          output type: text or json (default text)
  -p, --profile string       ~/.databrickscfg profile
  -t, --target string        bundle target to use (if applicable)
      --var strings          set values for variables defined in bundle config. Example: --var="foo=bar"
