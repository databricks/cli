
=== Deploy a schema with a volume in it
>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Created schemas.schema1
Created volumes.volume1
Files: 2 uploaded, 0 deleted
Resources: 2 created, 0 changed, 0 deleted, 0 unchanged

=== Rename the volume out of band
>>> [CLI] volumes update main.test-schema-[UNIQUE_NAME].myvolume --new-name myvolume2
{
  "full_name": "main.test-schema-[UNIQUE_NAME].myvolume2",
  "volume_id": "[VOLUME_ID]"
}

=== With the config unchanged, the plan creates the volume again under its configured name
>>> [CLI] bundle plan
create volumes.volume1

Plan: 1 to add, 0 to change, 0 to delete, 1 unchanged
