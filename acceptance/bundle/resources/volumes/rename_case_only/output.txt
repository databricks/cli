=== Rename the schema. The volume is re-keyed without a request. Its recorded ID keeps the config's casing, which UC reads case-insensitively

>>> update_file.py databricks.yml test_schema_ test_schema_renamed_

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Updated schemas.schema1
Files: 1 uploaded, 0 deleted
Resources: 0 created, 1 changed, 0 deleted, 1 unchanged

  "body": {
