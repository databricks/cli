
=== A failed upload after create keeps the app in state and leaves the thumbnail out of it

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle/default/files...
Warning: failed to upload the thumbnail of app myappname, the next deploy retries it: Unsupported image
Created apps.mykey
Files: 2 uploaded, 0 deleted
Resources: 1 created, 0 changed, 0 deleted, 0 unchanged

>>> jq .state["resources.apps.mykey"].state.thumbnail .databricks/bundle/default/resources.json
null

=== The next deploy retries the upload

>>> [CLI] bundle plan
update apps.mykey

Plan: 0 to add, 1 to change, 0 to delete, 0 unchanged

>>> musterr [CLI] bundle deploy
