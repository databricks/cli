
=== Outside the bundle, create an endpoint with the name the bundle uses, but of another endpoint_type

>>> [CLI] vector-search-endpoints create-endpoint vs-endpoint-[UNIQUE_NAME] STORAGE_OPTIMIZED --no-wait
{
  "name": "vs-endpoint-[UNIQUE_NAME]",
  "endpoint_type": "STORAGE_OPTIMIZED"
}

=== The bundle's create request fails with a 504 that the backend did not apply: deploy takes the endpoint

>>> [CLI] bundle deploy
