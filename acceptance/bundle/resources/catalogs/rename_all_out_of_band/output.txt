
=== Deploy a catalog with a schema and a volume in it
>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Created catalogs.catalog1
Created schemas.schema1
Created volumes.volume1
Files: 2 uploaded, 0 deleted
Resources: 3 created, 0 changed, 0 deleted, 0 unchanged

=== Rename the volume, the schema and the catalog out of band
>>> [CLI] volumes update test_catalog_[UNIQUE_NAME].myschema.myvolume --new-name myvolume2
{
  "full_name": "test_catalog_[UNIQUE_NAME].myschema.myvolume2"
}

>>> [CLI] schemas update test_catalog_[UNIQUE_NAME].myschema --new-name myschema2
{
  "full_name": "test_catalog_[UNIQUE_NAME].myschema2"
}

>>> [CLI] catalogs update test_catalog_[UNIQUE_NAME] --new-name test_catalog_renamed_[UNIQUE_NAME]
{
  "name": "test_catalog_renamed_[UNIQUE_NAME]"
}

=== Rename all three in the config to match
>>> update_file.py databricks.yml test_catalog_ test_catalog_renamed_

>>> update_file.py databricks.yml name: myschema name: myschema2

>>> update_file.py databricks.yml name: myvolume name: myvolume2
