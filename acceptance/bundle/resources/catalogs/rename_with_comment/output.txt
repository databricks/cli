=== Rename the catalog and change its comment in one deploy: both go in one PATCH

>>> update_file.py databricks.yml test_catalog_ test_catalog_renamed_

>>> update_file.py databricks.yml comment: c1 comment: c2

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Updated catalogs.catalog1
Files: 2 uploaded, 0 deleted
Resources: 0 created, 1 changed, 0 deleted, 0 unchanged

>>> print_requests.py //unity-catalog
{
  "method": "PATCH",
  "path": "/api/2.1/unity-catalog/catalogs/test_catalog_[UNIQUE_NAME]",
  "body": {
    "comment": "c2",
    "custom_max_retention_hours": 0,
    "new_name": "test_catalog_renamed_[UNIQUE_NAME]"
  }
}
