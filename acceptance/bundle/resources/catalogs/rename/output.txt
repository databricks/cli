>>> [CLI] bundle deploy

=== The old catalog is gone and the schema and the volume are under the new one
old catalog is gone

>>> [CLI] schemas get test_catalog_renamed_[UNIQUE_NAME].myschema
{
  "full_name": "test_catalog_renamed_[UNIQUE_NAME].myschema",
  "catalog_name": "test_catalog_renamed_[UNIQUE_NAME]"
}

>>> [CLI] volumes read test_catalog_renamed_[UNIQUE_NAME].myschema.myvolume
{
  "full_name": "test_catalog_renamed_[UNIQUE_NAME].myschema.myvolume",
  "catalog_name": "test_catalog_renamed_[UNIQUE_NAME]"
}

=== The schema_id and volume_id are preserved, so these are the same objects
schema_id is unchanged
volume_id is unchanged
