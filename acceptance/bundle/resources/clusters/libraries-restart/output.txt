
=== Install (create): libraries install on the fresh cluster with no restart
>>> print_requests.py //clusters/restart

=== Update: adding a library does not restart the running cluster
>>> print_requests.py //clusters/restart

=== Delete: emptying the libraries list uninstalls them without restarting the running cluster
>>> print_requests.py //libraries/uninstall //clusters/restart
