
=== Install (create): libraries install on the fresh cluster with no restart
>>> print_requests.py //clusters/restart

=== Update: adding a library restarts the running cluster
>>> print_requests.py //clusters/restart
{
  "method": "POST",
  "path": "/api/2.1/clusters/restart",
  "body": {
    "cluster_id": "[UUID]"
  }
}

=== Delete: removing all libraries restarts the running cluster
>>> print_requests.py //clusters/restart
{
  "method": "POST",
  "path": "/api/2.1/clusters/restart",
  "body": {
    "cluster_id": "[UUID]"
  }
}

>>> [CLI] bundle destroy --auto-approve
The following resources will be deleted:
  delete resources.clusters.mycluster

All files and directories at the following location will be deleted: /Workspace/Users/[USERNAME]/.bundle/[UNIQUE_NAME]
