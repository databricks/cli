
=== Deploy a cluster with a pypi library
=== Removing the whole libraries block plans a delete of the libraries sub-resource
>>> [CLI] bundle plan
delete clusters.mycluster.libraries

Plan: 0 to add, 0 to change, 1 to delete, 1 unchanged

=== Redeploy uninstalls the libraries and restarts the running cluster
>>> [CLI] bundle destroy --auto-approve
The following resources will be deleted:
  delete resources.clusters.mycluster

All files and directories at the following location will be deleted: /Workspace/Users/[USERNAME]/.bundle/[UNIQUE_NAME]

Destroy: 1 deleted
