
=== Deploy should fail when variable used for secret has a default value
>>> [CLI] bundle deploy
Error: Variable used for secret value must not have a default value
  at resources.secrets.secret1.value
  in databricks.yml:7:14
     databricks.yml:15:14

The variable "secret_value" used for the secret "secret1" must not have a default value.
A default value is stored in plain text in the configuration file, which defeats the purpose of using a variable reference for a secret.
Remove the default value and pass the secret value at deployment time using "--var", the BUNDLE_VAR_secret_value environment variable, or a variable overrides file.


Exit code: 1
