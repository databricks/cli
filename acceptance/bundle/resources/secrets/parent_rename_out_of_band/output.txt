
=== Deploy a schema with a secret in it

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Created schemas.schema1
Created secrets.secret1
Files: 2 uploaded, 0 deleted
Resources: 2 created, 0 changed, 0 deleted, 0 unchanged

=== Rename the schema out of band. UC moves the secret with it

>>> [CLI] schemas update main.test-schema-[UNIQUE_NAME] --new-name test-schema-renamed-[UNIQUE_NAME]
{
  "full_name": "main.test-schema-renamed-[UNIQUE_NAME]"
}

=== With the config renamed to match, the plan finds the schema by its schema_id. A secret has no such id, so the plan creates it again

>>> update_file.py databricks.yml test-schema- test-schema-renamed-

>>> [CLI] bundle plan
create secrets.secret1

Plan: 1 to add, 0 to change, 0 to delete, 1 unchanged
