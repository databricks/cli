
=== Deploy should fail when a secret uses a variable that is not marked sensitive while other variables are
>>> [CLI] bundle deploy
Error: Variable used for secret value must be marked as sensitive
  at resources.secrets.secret2.value
  in databricks.yml:22:14

The variable "other_secret_value" used for the secret "secret2" must be marked as sensitive.
This bundle marks variables as sensitive, so only those are redacted in the output of "bundle validate -o json". Add "sensitive: true" to the variable definition.


Exit code: 1
