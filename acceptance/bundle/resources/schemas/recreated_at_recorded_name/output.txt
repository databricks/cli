=== Out of band, drop the schema and create it again under the same name

>>> [CLI] schemas delete main.test-schema-[UNIQUE_NAME] --force

If the bundle's was renamed outside the bundle, set its name in the config to the new one. If this object is the bundle's (deleted and created again outside the bundle), run 'bundle deployment unbind' and then 'bundle deployment bind' to manage it again.
