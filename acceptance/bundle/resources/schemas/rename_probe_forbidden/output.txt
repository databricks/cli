=== Delete the schema out of band and rename it in the config. Reading the new name is forbidden, so the plan only warns and creates the schema

>>> [CLI] schemas delete main.myschema

>>> update_file.py databricks.yml name: myschema name: myschema2

>>> [CLI] bundle plan
Warn: planning resources.schemas.schema1: looking for a moved resource at id="main.myschema2": User does not have USE SCHEMA on Schema main.myschema2
create schemas.schema1

Plan: 1 to add, 0 to change, 0 to delete, 0 unchanged

>>> errcode [CLI] bundle destroy --auto-approve
