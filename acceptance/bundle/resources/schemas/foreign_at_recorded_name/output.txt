
=== Deploy a schema

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Created schemas.schema1
Files: 3 uploaded, 0 deleted
Resources: 1 created, 0 changed, 0 deleted, 0 unchanged

=== Out of band, rename the schema away, and create another one under its name

>>> [CLI] schemas update main.test-schema-[UNIQUE_NAME] --new-name test-schema-moved-[UNIQUE_NAME]
{
  "full_name": "main.test-schema-moved-[UNIQUE_NAME]",
  "schema_id": "[SCHEMA_ID]"
}

=== The other schema has another schema_id, so the plan does not take it for the bundle's: it plans a create

>>> [CLI] bundle plan --output json
Warning: resources.schemas.schema1: id="main.test-schema-[UNIQUE_NAME]" holds another object: its schema_id is "[FOREIGN_SCHEMA_ID]", not "[SCHEMA_ID]" as recorded, so this bundle does not take it for its own. If the bundle's was renamed outside the bundle, set its name in the config to the new one. If this object is the bundle's (deleted and created again outside the bundle), run 'bundle deployment unbind' and then 'bundle deployment bind' to manage it again.

{
  "action": "create",
  "new_state": {
    "value": {
      "catalog_name": "main",
      "comment": "c1",
      "name": "test-schema-[UNIQUE_NAME]"
    }
  },
  "changes": {
    "schema_id": {
      "action": "skip",
      "reason": "internal_id",
      "old": "[SCHEMA_ID]"
    }
  }
}

>>> [CLI] bundle plan --output json

  "id": "main.test-schema-moved-[UNIQUE_NAME]",
  "action": "update_id",
  "state_only": true,
  "new_state": {
    "value": {
      "catalog_name": "main",
      "comment": "c1",
      "name": "test-schema-moved-[UNIQUE_NAME]"
    }
  },
  "changes": {
    "name": {
      "action": "skip",
      "reason": "remote_already_set",
      "old": "test-schema-[UNIQUE_NAME]",
      "new": "test-schema-moved-[UNIQUE_NAME]",

=== Deploy takes the renamed schema for the bundle's, and sends nothing to the other one

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Files: 1 uploaded, 0 deleted
Resources: 0 created, 0 changed, 0 deleted, 1 unchanged

>>> print_requests.py //unity-catalog

>>> [CLI] schemas get main.test-schema-moved-[UNIQUE_NAME]
{
  "full_name": "main.test-schema-moved-[UNIQUE_NAME]",
  "schema_id": "[SCHEMA_ID]"
}

>>> [CLI] schemas get main.test-schema-[UNIQUE_NAME]
{
  "full_name": "main.test-schema-[UNIQUE_NAME]",
  "schema_id": "[FOREIGN_SCHEMA_ID]"
}
