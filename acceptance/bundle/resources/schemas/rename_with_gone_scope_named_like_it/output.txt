
=== Deploy a schema and a secret scope whose name starts with the schema's full name

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle/default/files...
Created schemas.schema1
Created secret_scopes.scope1
Created secret_scopes.scope1.permissions
Files: 3 uploaded, 0 deleted
Resources: 3 created, 0 changed, 0 deleted, 0 unchanged

=== Out of band: rename the schema, delete the scope, and create another scope named like the renamed schema

>>> [CLI] schemas update main.myschema --new-name moved_schema
{
  "full_name": "main.moved_schema",
  "schema_id": "[UUID]"
}

>>> [CLI] secrets delete-scope main.myschema.scope

>>> [CLI] secrets create-scope main.moved_schema.scope

=== The config follows the rename and drops the scope: the other scope is not the bundle's, and is left alone

>>> [CLI] bundle deploy --auto-approve
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle/default/files...
Files: 3 uploaded, 0 deleted
Resources: 0 created, 0 changed, 0 deleted, 1 unchanged

>>> print_requests.py --sort //unity-catalog //secrets

>>> [CLI] secrets list-scopes -o json
["main.moved_schema.scope"]
