
=== Deploy a schema with a volume in it
>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Created schemas.schema1
Created volumes.volume1
Files: 2 uploaded, 0 deleted
Resources: 2 created, 0 changed, 0 deleted, 0 unchanged

=== Rename the schema out of band. UC moves the volume with it
>>> [CLI] schemas update main.test-schema-[UNIQUE_NAME] --new-name test-schema-renamed-[UNIQUE_NAME]
{
  "full_name": "main.test-schema-renamed-[UNIQUE_NAME]",
  "schema_id": "[SCHEMA_ID]"
}

=== With the config unchanged, the plan creates the schema and the volume again under their configured names
>>> [CLI] bundle plan
create schemas.schema1
create volumes.volume1

Plan: 2 to add, 0 to change, 0 to delete, 0 unchanged
