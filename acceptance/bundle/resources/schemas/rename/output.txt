=== Deploy renames the schema without a deletion prompt
>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Updated schemas.schema1
Files: 1 uploaded, 0 deleted
Resources: 0 created, 1 changed, 0 deleted, 0 unchanged

>>> print_requests.py //unity-catalog
{
  "method": "PATCH",
  "path": "/api/2.1/unity-catalog/schemas/main.test-schema-[UNIQUE_NAME]",
  "body": {
    "comment": "COMMENT1",
    "custom_max_retention_hours": 0,

  }
}

=== The schema is only reachable under the new name, with its original schema_id
>>> musterr [CLI] schemas get main.test-schema-[UNIQUE_NAME]
Error: Schema 'main.test-schema-[UNIQUE_NAME]' does not exist.

>>> [CLI] schemas get main.test-schema-renamed-[UNIQUE_NAME]
{
  "full_name": "main.test-schema-renamed-[UNIQUE_NAME]",
  "name": "test-schema-renamed-[UNIQUE_NAME]",
  "comment": "COMMENT1",
  "schema_id": "[SCHEMA_ID]"
}

=== The state and summary track the new name
>>> [CLI] bundle summary --output json
{
  "id": "main.test-schema-renamed-[UNIQUE_NAME]",
  "name": "test-schema-renamed-[UNIQUE_NAME]"
}
