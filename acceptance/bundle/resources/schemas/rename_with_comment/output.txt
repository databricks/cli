=== Rename the schema and change its comment in one deploy: both go in one PATCH
>>> update_file.py databricks.yml test-schema- test-schema-renamed-

>>> update_file.py databricks.yml comment: c1 comment: c2

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Updated schemas.schema1
Files: 2 uploaded, 0 deleted
Resources: 0 created, 1 changed, 0 deleted, 0 unchanged

>>> print_requests.py //unity-catalog
{
  "method": "PATCH",
  "path": "/api/2.1/unity-catalog/schemas/main.test-schema-[UNIQUE_NAME]",
