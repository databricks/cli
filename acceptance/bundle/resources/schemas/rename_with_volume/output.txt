=== Deploy renames the schema. UC moves the volume with it, so the volume gets no request
>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Updated schemas.schema1
Updated volumes.volume1
Files: 1 uploaded, 0 deleted
Resources: 0 created, 2 changed, 0 deleted, 0 unchanged

>>> print_requests.py //unity-catalog
{
  "method": "PATCH",
  "path": "/api/2.1/unity-catalog/schemas/main.test-schema-[UNIQUE_NAME]",
  "body": {
    "comment": "",
    "custom_max_retention_hours": 0,
    "new_name": "test-schema-renamed-[UNIQUE_NAME]"
  }
}

=== The old schema is gone and the volume is under the new one
>>> musterr [CLI] schemas get main.test-schema-[UNIQUE_NAME]
Error: Schema 'main.test-schema-[UNIQUE_NAME]' does not exist.

>>> [CLI] volumes read main.test-schema-renamed-[UNIQUE_NAME].myvolume
{
  "full_name": "main.test-schema-renamed-[UNIQUE_NAME].myvolume",
  "schema_name": "test-schema-renamed-[UNIQUE_NAME]"
}

=== The volume_id is preserved, so this is the same volume
volume_id is unchanged

"main.test-schema-renamed-[UNIQUE_NAME].myvolume"
