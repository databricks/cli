
=== Create a schema carrying the owner property that SQL's CREATE SCHEMA leaves on it

>>> [CLI] schemas create --json {"name": "schema_sql_owner", "catalog_name": "main", "properties": {"owner": "root"}}
{
  "full_name": "main.schema_sql_owner",
  "properties": {
    "owner": "root"
  }
}

=== Bind it: the config matches, so there is nothing to confirm

>>> [CLI] bundle deployment bind schema1 main.schema_sql_owner
