
=== The domain is not part of the bundle: it is created outside of it

=== The lookup resolves the tag key of the domain to its ID

>>> [CLI] bundle validate -o json
{
  "variable": "[UUID][0]",
  "domain": "domains/[UUID][0]"
}

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle/default/files...
Created pages.chargeback
Files: 1 uploaded, 0 deleted
Resources: 1 created, 0 changed, 0 deleted, 0 unchanged

>>> print_requests.py //knowledge
{
  "method": "POST",
  "path": "/api/2.0/knowledge/pages",

    "request_id": "[UUID][1]"

  "body": {

=== Destroying the bundle deletes the page and keeps the domain

>>> [CLI] bundle destroy --auto-approve
The following resources will be deleted:
  delete resources.pages.chargeback

This action will result in the deletion of the following pages.
A deleted page cannot be restored:
  delete resources.pages.chargeback

All files and directories at the following location will be deleted: /Workspace/Users/[USERNAME]/.bundle/test-bundle/default

Destroy: 1 deleted

>>> [CLI] domains get-domain domains/[UUID][0]
{
  "tag_key": "Payments"
}
