
=== Deploy a model and register two versions of it out of band

>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/test-bundle-[UNIQUE_NAME]/default/files...
Created registered_models.model1
Files: 2 uploaded, 0 deleted
Resources: 1 created, 0 changed, 0 deleted, 0 unchanged

>>> register_model_version main.default.model-[UNIQUE_NAME]
1

>>> register_model_version main.default.model-[UNIQUE_NAME]
2

=== Rename the model and point 'champion' at version 2 in one deploy. The alias is set first, under the current name

>>> update_file.py databricks.yml name: model- name: model2-

>>> update_file.py databricks.yml aliases: [] aliases: [{alias_name: champion, version_num: 2}]

>>> [CLI] bundle deploy

>>> register_model_version main.default.model2-[UNIQUE_NAME]
3
