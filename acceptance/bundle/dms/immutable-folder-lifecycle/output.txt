=== A changed file recreates the snapshot, and both resources are recorded at version 2
>>> [CLI] bundle deploy
Recreated internal_immutable_snapshots.immutable
Updated jobs.foo
Files: 0 uploaded, 0 deleted
Resources: 1 created, 1 changed, 1 deleted, 0 unchanged

>>> MSYS_NO_PATHCONV=1 [CLI] bundle-deployments list-resources deployments/[DEPLOYMENT_ID] -o json
[
  {
    "last_action_type": "OPERATION_ACTION_TYPE_RECREATE",
    "last_version_id": "2",
    "resource_key": "internal_immutable_snapshots.immutable"
  },
  {
    "last_action_type": "OPERATION_ACTION_TYPE_UPDATE",
    "last_version_id": "2",
    "resource_key": "jobs.foo"
  }
]
