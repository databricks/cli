=== The remote backup preserves the original direct state byte for byte
>>> MSYS_NO_PATHCONV=1 [CLI] workspace export /Workspace/Users/[USERNAME]/.bundle/dms-existing-state-[UNIQUE_NAME]/default/state/resources.json.backup --format RAW --file .databricks/resources.backup.first.json

>>> cmp .databricks/resources.before-dms.json .databricks/resources.backup.first.json
