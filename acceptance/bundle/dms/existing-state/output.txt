
=== Config disables recording even when the environment enables it
>>> DATABRICKS_BUNDLE_DEPLOYMENT_HISTORY=true [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/dms-existing-state-[UNIQUE_NAME]/default/files...
Created jobs.one
Created jobs.two
Files: 2 uploaded, 0 deleted
Resources: 2 created, 0 changed, 0 deleted, 0 unchanged

>>> cp .databricks/bundle/default/resources.json .databricks/resources.before-dms.json

>>> jq {state_version, serial, features} .databricks/bundle/default/resources.json
{
  "state_version": 3,
  "serial": 1,
  "features": null
}

=== Normal state selection prefers local serial 2 over remote serial 1
>>> update_file.py .databricks/bundle/default/resources.json "serial": 1 "serial": 2

>>> jq -c {serial} .databricks/bundle/default/resources.json
{"serial":2}
