
=== Deploying from a git repo records where the source came from: the version carries git_info, workspace_info and the target's deployment_mode
>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/dms-provenance/dev/files...
Deploying resources...
Updating deployment state...
Deployment complete!
Deployment history: [DATABRICKS_URL]/deployments/[NUMID]?version=1
