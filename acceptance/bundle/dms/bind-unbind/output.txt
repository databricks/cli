
=== Bind an existing job with deployment history enabled
>>> [CLI] bundle deployment bind foo [JOB_ID] --auto-approve
Successfully bound job with an id '[JOB_ID]'
Run 'bundle deploy' to deploy changes to your workspace

=== Deploy keeps the bound job ID and enables shadow history
>>> [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/dms-bind-unbind-[UNIQUE_NAME]/default/files...
Updated jobs.foo
Files: 2 uploaded, 0 deleted
Resources: 0 created, 1 changed, 0 deleted, 0 unchanged

>>> jq {features, resource_id: .state["resources.jobs.foo"].__id__} .databricks/bundle/default/resources.json
{
  "features": {
    "deployment_history_shadow": {}
  },
  "resource_id": "[JOB_ID]"
}

=== Unbind preserves the shadow history marker and leaves the job intact
>>> [CLI] bundle deployment unbind foo

>>> jq {features, state} .databricks/bundle/default/resources.json
{
  "features": {
    "deployment_history_shadow": {}
  },
  "state": {}
}

>>> [CLI] jobs get [JOB_ID]
{
  "job_id": [JOB_ID]
}

=== Rebind preserves the existing shadow history marker
>>> [CLI] bundle deployment bind foo [JOB_ID] --auto-approve
Successfully bound job with an id '[JOB_ID]'
Run 'bundle deploy' to deploy changes to your workspace

>>> jq {features, resource_id: .state["resources.jobs.foo"].__id__} .databricks/bundle/default/resources.json
{
  "features": {
    "deployment_history_shadow": {}
  },
  "resource_id": "[JOB_ID]"
}
