=== Reopening reads resources from the file and produces a no-op plan
>>> [CLI] bundle plan
Plan: 0 to add, 0 to change, 0 to delete, 1 unchanged

>>> print_requests.py --dms //resources --get --oneline

=== Disabling deployment history allows plan and deploy, and removes the file marker
>>> env DATABRICKS_BUNDLE_DEPLOYMENT_HISTORY=false [CLI] bundle plan
update jobs.foo

Plan: 0 to add, 1 to change, 0 to delete, 0 unchanged

>>> env DATABRICKS_BUNDLE_DEPLOYMENT_HISTORY=false [CLI] bundle deploy
Uploading bundle files to /Workspace/Users/[USERNAME]/.bundle/dms-state-features-[UNIQUE_NAME]/default/files...
Updated jobs.foo
Files: 1 uploaded, 0 deleted
Resources: 0 created, 1 changed, 0 deleted, 0 unchanged

>>> jq .features // {} .databricks/bundle/default/resources.json
{}

>>> print_requests.py --dms //api/2.0/bundle --oneline

=== Removing the YAML setting also leaves history disabled
>>> env DATABRICKS_BUNDLE_DEPLOYMENT_HISTORY=false [CLI] bundle plan
Plan: 0 to add, 0 to change, 0 to delete, 1 unchanged
