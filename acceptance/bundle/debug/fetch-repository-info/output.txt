
=== from the worktree root

>>> [CLI] bundle debug fetch-repository-info --output json
{
  "worktree_root": "[TEST_TMP_DIR]",
  "current_branch": "main",
  "latest_commit": "[COMMIT_SHA]",
  "origin_url": "https://github.com/databricks/cli.test"
}
=== from a subdirectory (resolves to the same worktree root)

>>> [CLI] bundle debug fetch-repository-info --path a/b/c --output json
{
  "worktree_root": "[TEST_TMP_DIR]",
  "current_branch": "main",
  "latest_commit": "[COMMIT_SHA]",
  "origin_url": "https://github.com/databricks/cli.test"
}

{

  "current_branch": "",
  "latest_commit": "",
