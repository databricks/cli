=== Without a root_path or test sources, test selections must be workspace paths
>>> musterr [CLI] pipelines test --pipeline-id [UUID] tests
Error: cannot resolve test selection "tests": the pipeline has no root_path or testing.sources; use an absolute workspace path such as /Workspace/Users/someone@example.com/tests

=== Outside a project, --pipeline-id is required
>>> musterr [CLI] pipelines test tests
Error: outside a project, identify the pipeline with --pipeline-id
