
=== Each decoded key is printed; two Ctrl+C exit

>>> [CLI] selftest tui keys --timeout 5s
[?25l[?2004hkey="a" type=-1 runes="a" alt=false paste=false
key="ctrl+c" type=3 runes="" alt=false paste=false
key="ctrl+c" type=3 runes="" alt=false paste=false

 
[2K
[?2004l[?25h[?1002l[?1003l[?1006l
=== --raw prints the bytes read from stdin

>>> [CLI] selftest tui keys --raw
raw bytes=61 62 03 03 text="ab\x03\x03"

=== --timeout exits without any input

>>> [CLI] selftest tui keys --timeout 1s
[?25l[?2004h
 
[2K
[?2004l[?25h[?1002l[?1003l[?1006l
