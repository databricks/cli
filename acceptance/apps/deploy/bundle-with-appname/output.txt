=== API and bundle deploy flags cannot be mixed
>>> musterr [CLI] apps deploy --source-code-path /Workspace/apps/test-app --force
Error: API deploy flags --source-code-path cannot be combined with bundle deploy flags --force

>>> musterr [CLI] apps deploy --git-branch release --skip-validation
Error: API deploy flags --git-branch cannot be combined with bundle deploy flags --skip-validation

>>> musterr [CLI] apps deploy test-app --no-wait --target prod
Error: API deploy flags --no-wait cannot be combined with bundle deploy flags --target

>>> musterr [CLI] apps deploy --no-wait --var app_name=my-app
Error: API deploy flags --no-wait cannot be combined with bundle deploy flags --var
